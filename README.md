# About SplitBuddies-Android

**Split Buddies** Split Buddies is a mobile app designed to simplify group expense management. Whether you're on a trip, sharing rent, or organizing an event, Split Buddies helps you track who owes what and settle up with ease. Features include real-time syncing via Firebase, user-friendly interfaces built in Android Studio, and group-based expense breakdowns.
> [!WARNING]
> This APK file is a debug.apk. Split Buddies is still in development, so be aware of the risks when downloading a early staged .apk file.

## Getting Started

To get a local copy up and running:

### Prerequisites
- Third-party app installer. (Obtainium recommended)
- Allow the app installer to install apps.

### Instructions
1. Copy the [Spit Buddies repo](https://github.com/ANavarrete00/SplitBuddies-Android) link.
2. In Obtainium, click the _Add_ button to add the a repo.
3. Add the repo link you copied to the _App source URL_ box.
4. Toggle the _Include prereleases_ button.
5. Finish adding the repo and install the app.

---

## Usage

Create a group, add expenses, assign people, and track who owes what. Automatic calculation and balance summaries make it easy to manage shared costs.
